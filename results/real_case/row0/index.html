What actually runs

QPIE image preparation→Controlled coordinate shift→Hadamard interference→Measurement

Every 16 × 16 block runs four Qiskit circuits. Overlapping halos retain neighboring pixels at block boundaries. The entire image is processed automatically, and the live strength map updates from completed circuit measurements.

Execution uses a local ideal Qiskit Aer statevector simulator. It is not a quantum hardware run. Aer executes image initialization as a supported preparation instruction; a decomposed circuit example is available below.
